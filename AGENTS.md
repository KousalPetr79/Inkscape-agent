# Repository instructions

- Use English for all source code, documentation, comments, commit messages, issues, and pull requests.
- Treat this repository as public. Never add credentials, access tokens, private keys, personal information, private filesystem paths, or confidential document contents.
- Use synthetic, non-sensitive data in examples and tests.
- Keep the platform-independent SVG/XML core separate from operating-system transport adapters.
- Mark untested platform behavior explicitly; do not report command success as proof of a visual Inkscape change.
- Preserve user documents by default. Use backups, working copies, validation, and explicit confirmation for destructive operations.
- Never force-push or rewrite published history unless the repository owner explicitly requests it.
